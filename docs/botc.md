# Blood on the Clocktower (BotC)

블러드 온 더 클락타워(피바람 부는 시계탑)의 기본 진행 방식과 규칙 요약입니다.

## 기본 개요
- **마을 주민(Good)** 진영과 **악마(Evil)** 진영의 블러핑 마피아 게임입니다.
- 죽은 플레이어도 게임에 계속 참여하며 토론하고 투표할 수 있습니다(단, 투표권은 1회로 제한됨).

## 낮과 밤의 흐름
1. **밤 (Night)**: 악마와 미니언이 눈을 뜨고 능력을 사용합니다. 정보 획득 직업군도 정보를 얻습니다.
2. **낮 (Day)**: 모든 플레이어가 자유롭게 돌아다니며 비밀 대화를 나누고(귓속말), 이후 다 같이 모여 투표로 처형할 사람을 정합니다.

자세한 시나리오별 캐릭터 능력은 추후 업데이트 됩니다.
