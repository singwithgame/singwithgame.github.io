# 보드게임 가이드 및 규칙서

왼쪽 사이드바에서 원하시는 게임의 가이드 문서를 선택해주세요. 

새로운 가이드를 작성하시면 자동으로 사이드바에 추가됩니다!

---

## 💡 팁: 사이드바 순서와 폴더 관리 (Docs as Code)

이 사이트는 **마크다운(MD) 파일만으로 모든 구조가 통제**됩니다.

1. **사이드바 순서 바꾸기**
   문서의 맨 위(Frontmatter)에 `sidebar_position: 숫자`를 적어주시면, 해당 숫자에 맞춰 사이드바 순서가 자동으로 정렬됩니다.
2. **새로운 게임 메뉴 만들기**
   깃허브 저장소의 `docs/` 폴더 안에 새로운 폴더(예: `docs/splendor`)를 만들고 마크다운 파일을 넣기만 하면, 사이드바에 'Splendor' 메뉴가 알아서 뿅 하고 생겨납니다.
